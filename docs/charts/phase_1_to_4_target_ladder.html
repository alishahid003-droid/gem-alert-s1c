Supersedes the earlier 5-phase, 0%-bust-rate chart (docs/charts/phase_1_to_5_target_ladder.html, committed under commit c3a243c) - that model applied a single average multiple-per-trade with zero variance, which cannot mathematically produce a loss, let alone a bust. This chart uses real per-trade win/loss outcomes from Ali's own 39 closed compound trades, real pool-liquidity data from 38 priced trades, the live drawdown breaker (50% of peak), and the corrected liquidity stake cap (5%, commit 1f9e895).

What changed to get here

Three revisions in one night, each closing a real gap: (1) added real trade variance instead of an average multiple; (2) added realistic reseed-after-breaker-trip behavior instead of treating one trip as the end; (3) added the real liquidity stake cap (raised from a never-approved 2% default to 5%), which fixed the contradiction where Phase 4 (200x) looked faster than Phase 3 (52.5x) - bigger targets now correctly take longer, bound by how much any single memecoin pool can actually absorb per trade.
